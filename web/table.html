Обработка таблицы с новыми строками

Загрузите исходную таблицу в том же формате, например с добавленными строками. Нужен лист "Задание 1" с колонками: правообладатель, автор, название, тип контента, url, сайт. Лист "Задание 2" необязателен.

В ответ скачается обработанная таблица с теми же листами, что и готовая. ID уже известных книг не меняются, новые строки получают ID своей книги или новый, дубли и спорные случаи пересчитываются. Для адресов, которые уже проверялись, подставляется результат проверки страницы.
