# Проверка решения

Проверены исходный PDF, оба листа Excel, правила обработки, выгрузки и опубликованный интерфейс.

## Что исправлено

- Инициалы сохраняются при формировании ключа автора. Разные авторы с одной фамилией не объединяются только из-за удаления инициалов.
- При нескольких совпадениях прототип возвращает статус 2 вместо произвольного выбора книги.
- Явно указанный автор проверяется отдельно от имён в рекомендациях. Примечания автора не считаются его именем.
- Короткий PDF больше не считается фрагментом по одному лишь количеству страниц.
- Упоминание магазина не доказывает отсутствие размещения. Противоречивые признаки требуют проверки человеком.
- Незавершённая загрузка при превышении лимита не выдаётся за полный ответ сайта.
- Исходные значения сохраняются отдельно от очищенных. Строки, начинающиеся со знака равенства, записываются как текст, а не формулы.
- Файлы проверяются по распакованному размеру, читаются потоково, ограничения действуют на оба используемых листа.

## Интерфейс

Общая навигация, мобильная версия, фильтр статусов, поиск по результатам, раскрытие извлечённых данных, понятные сообщения ошибок. Старый результат скрывается при новом запуске. Повторная отправка Excel блокируется до завершения обработки. В обзоре отображается сохранённый прогон с датой, а не статическая таблица с прежними выводами.

## Проверки

- test_rules.py: исходные правила и регрессии сопоставления.
- test_uploads.py: обычный файл, неправильный формат, большой распакованный архив, превышение строк во втором листе, исходные значения и формулы.
- Сверка исходных значений всех строк обоих листов с результатом.
- Проверка браузером: десктоп и ширина 390 пикселей, фильтры и пустая выдача.
- Новый серверный прогон 147 URL. По части 2: семь статусов 1, один статус 0, два статуса 2.

## Границы результата

Результат остаётся эвристическим прототипом, а не юридическим заключением. Автоматические статусы не заменяют ручную разметку для измерения точности. Эталонного внешнего каталога нет: использованы метаданные обоих листов, это указано в записке. Полнота книг и реальная доступность каждого скачиваемого файла не проверялись. Для нового домена правило объединения зеркал нужно подтвердить.

## Дополнительная проверка качества через ИИ

Подключён API429 с моделью gemini-3.5-flash-lite. Реальный запрос и опубликованный API проверены.
Спорные доступные страницы разбираются дополнительно. Идентификаторы книг и дословные цитаты проверяются кодом.
Ошибки загрузки не принимаются как доказательство отсутствия размещения. При отказе API или непроверяемом ответе сохраняется исходное решение.
На примере страницы knigoline.ru ИИ уточнил статус 2 до 0 по подтверждённой цитате о покупке на Литрес.
В сохранённом прогоне задания 2: 7 статусов 1, 2 статуса 0, 1 статус 2. Изменение доли статуса 2 не считается измерением точности.

При обработке Excel можно добавить рекомендации по 8 спорным книгам. Номера строк и цитаты проверяются, исходные значения и каталог не меняются. В результате 150 строк, 91 книга, 17 дублей и отдельный лист с 8 рекомендациями.
Секрет API находится только в файле окружения на сервере, права 600. Ключ не передаётся браузеру, не включается в запрос модели и не хранится в репозитории.

## Проверка парсинга и понятности интерфейса

15 контрольных сценариев с заранее заданными статусом и книгой проходят. Устранены ложные совпадения похожих имён в одном алфавите и имён из блока рекомендаций; добавлено извлечение автора из микроразметки.
В разделе обработки таблицы загрузка и скачивание расположены рядом. Отдельно подписаны готовый результат задания и результат файла пользователя. Выбор другого файла скрывает прежний результат.
